# 拼图 —— 微信小程序拼图工具

> 把你的照片，拼成想要的样子。

一款纯前端的微信小程序拼图工具：无需登录、无需上传，所有处理都在手机本地完成，照片不出设备，隐私零顾虑。

## 功能特性

### 🧩 双拼接模式

- **模板拼接**：2~9 张照片，共 **70 组**预设布局——田字格、九宫格、一大 N 小、黄金比例分割、多行多列组合等拓扑全覆盖
- **简单拼接**：横排等高 / 竖排等宽，每张照片完整显示不裁剪，宽度（高度）自适应，适合长图拼接、聊天记录合并

### ✂️ 比例自由调整

布局不是死板的——拖动格间分割线，相邻单元格的宽高比例实时变化，微调到满意为止。

### 🔀 灵活的图片管理

- 拖拽即可交换任意两张照片的位置（带震动反馈与跟手浮层）
- 「调整位置」模式下可在格子内平移照片，自定义画面取景窗口
- 单击图片可替换，支持逐张补充与批量选图

### ⚙️ 细节可定制

- 照片间距粗细（滑杆）、间距颜色（取色板）随心调整
- 外框比例可切换（1:1 / 3:4 / 4:3 / 9:16 等）

### 📷 原清晰度导出

- 智能按各格原图实际分辨率推导导出尺寸，**任何一张照片都不会被放大**
- 上限受 iOS Canvas 保护（单边 4096px / 总面积 1600 万像素），在允许范围内取最高清晰度
- 导出间距与编辑页视觉一致（随画布等比缩放），所见即所得
- 一键保存到手机相册（含权限引导）

### ✨ 液态玻璃设计

全局苹果液态玻璃（Liquid Glass）视觉风格：多层光晕背景、釉面渐变玻璃、高光描边；自定义导航与系统胶囊精确对齐，底部安全区自动避让。

## 项目结构

```
├── project.config.json          # 小程序项目配置
├── miniprogram/
│   ├── app.js / app.json / app.wxss   # 全局入口与液态玻璃设计系统
│   ├── assets/logo.png
│   ├── core/                    # 核心算法（纯函数，与 UI 解耦）
│   │   ├── tree.js              # 分割树（split tree）布局模型 + computeLayout
│   │   ├── layouts.js           # 70 组布局模板定义
│   │   ├── export.js            # Canvas 导出（尺寸推导 / aspectFill / 拼接渲染）
│   │   ├── constants.js         # 常量（最小比例、比例档位、色板等）
│   │   └── selftest.js          # Node 自测脚本
│   ├── components/
│   │   ├── layout-picker/       # 布局缩略图选择器
│   │   └── color-palette/       # 间距颜色取色板
│   └── pages/
│       ├── index/               # 首页（开始拼图）
│       ├── editor/              # 编辑页（画布 / 手势 / 工具栏）
│       └── preview/             # 预览导出页
```

## 核心设计

- **分割树（split tree）布局模型**：叶子节点为图片格，内部节点为行/列分割 + 比例数组；`computeLayout` 为纯函数，交互层（视图渲染）与导出层（Canvas 绘制）共享同一输出，保证像素级一致
- **结构与内容分离**：树只管几何，`assignments` 数组管内容——交换图片只是换数组元素，平移量随图片对象自动携带
- **导出尺寸推导**：按每格原图分辨率反推画布尺寸，取各格上限的最小值，保证不放大、不降质

## 运行与测试

1. 使用微信开发者工具导入项目根目录
2. 运行核心布局算法自测（Node 环境）：

```bash
node miniprogram/core/selftest.js
```
